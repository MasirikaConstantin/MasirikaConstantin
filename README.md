## 👨‍💻 À propos de moi

- 🔭 Je travaille sur **Teka Hub**, une solution SaaS de gestion et de point de vente.
- 🏢 Je développe des solutions numériques avec **Niwy Tech**.
- 🌐 Je conçois des applications web, des API REST et des applications mobiles.
- 📱 Je travaille avec **Android natif**, **React Native** et **Expo**.
